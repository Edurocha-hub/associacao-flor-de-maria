# 💜 Associação Flor de Maria

Site institucional desenvolvido para a **Associação Flor de Maria**, uma organização social que realiza iniciativas voltadas à educação, ao acolhimento e à solidariedade.

O projeto tem como objetivo ampliar a presença digital da associação, facilitar o acesso às informações e aproximar a comunidade das atividades desenvolvidas.

## 📌 Sobre o projeto

Este site foi desenvolvido como parte de um **Projeto de Extensão Universitária** do curso de Análise e Desenvolvimento de Sistemas (ADS) da Universidade Paulista (UNIP).

A proposta consiste em aplicar conhecimentos de desenvolvimento web para atender a uma necessidade real da comunidade, contribuindo para a divulgação das atividades da associação.

O site apresenta informações institucionais, cursos, projetos sociais, formas de contribuição e canais de contato.

## 🚀 Funcionalidades

- Página inicial com apresentação da associação.
- Seção institucional "Quem Somos".
- Divulgação de cursos e atividades educacionais.
- Apresentação de projetos sociais.
- Informações sobre doações e voluntariado.
- Botões de contato direto pelo WhatsApp.
- Localização por meio do Google Maps.
- Layout responsivo para computadores, tablets e celulares.
- Navegação entre seções.
- Atualização automática do ano no rodapé.

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, responsividade e identidade visual.
- **JavaScript:** funcionalidades e comportamentos dinâmicos.
- **Git:** controle de versão.
- **GitHub:** armazenamento e gerenciamento do código-fonte.

## 💻 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/Edurocha-hub/associacao-flor-de-maria.git
```

2. Abra a pasta do projeto no Visual Studio Code.

3. Localize o arquivo `index.html`.

4. Abra o arquivo no navegador ou utilize a extensão Live Server.

O projeto utiliza tecnologias web nativas e não exige instalação de dependências.

## 📱 Responsividade

O site foi desenvolvido considerando diferentes tamanhos de tela.

Foram utilizados recursos de CSS, como Flexbox, Grid Layout e Media Queries, para adaptar os elementos aos dispositivos móveis.
